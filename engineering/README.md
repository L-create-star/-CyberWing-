## 计算公式（经典理论，含假设）

| 指标 | 公式 | 说明 |
|---|---|---|
| 展弦比 | AR = b²/S | 翼展²/翼面积 |
| 翼载荷 | W/S | kg/m² |
| 巡航升力系数 | CL = 2W/(ρV²S) | ρ 取 ISA 巡航高度密度 |
| 失速速度 | Vs = √(2W/(ρ·CLmax·S)) | 光洁 CLmax=1.5，襟翼 CLmax=2.5 |
| 巡航升阻比 | L/D = 1/(CD₀+CL²/(π·e·AR)) | CD₀=0.05（客机），e=0.75 |
| Breguet 航程 | R = (V/(TSFC·g))·(L/D)·ln(W₀/W₁) | TSFC=1.6e-5，W₁=0.8·W₀ |
| 起飞距离 | 滑跑 S_ground = V_R²/(2·a) + 爬升至 15m 水平距离 | a=(T-D-μW)/m |
| 着陆距离 | 进近 S_app = 15/tan(3°) + 地面制动 S_brake = V_TD²/(2·decel) | decel=(μb·W+D)/m |
| 爬升率 | ROC = (T-D)·V / W | 剩余功率法，随高度变化 |

**假设（文档化）**：ISA 大气模型（h≤11000m）；W₁/W₀=0.8；参数敏感性已说明。
**验证**：C919 估算航程 5642km vs 官方 5555km（误差 1.6%）；起飞距离 1510m，着陆距离 1265m。

## 数据来源原则

- 全部数据标注来源（波音/空客官网、中国商飞、公开报道）
- 不确定字段留空（`None`），前端显示"待核实"，**禁止编造**
- 翼面积等派生量标注推导依据（如 C919 由公开翼载 500kg/m² 反推）

## 前端使用

顶栏新增 **[ 工程分析 ]** 按钮 → 模态面板：
- 选择机型（30 架：12 民航 + 18 军用/运输，含 C919、ARJ21、737、A320neo、A321neo、737MAX、767-300ER、777-300ER、787、747-400/8、A330-900、A350、A380、F-16、F-15、F/A-18、F-22、F-35A、米格-29、苏-27/57、歼-10C/20/35A、枭龙、F-86、P-51、B-25、运-20）
- 修改翼展/翼面积/MTOW/巡航速度/高度 → 实时重算
- 地面性能参数：总推力/摩擦系数/制动系数/起飞CL/着陆CL
- 输出：AR、W/S、CL、L/D、失速速度、Breguet 航程估算 + 官方航程对照
- 输出：起飞距离（滑跑+爬升）、着陆距离（进近+制动）
- 「重置为官方参数」一键复原

### ECharts 可视化（七标签页）
1. **CL-α 升力曲线**：有限翼展升力线斜率 a=2π·AR/(AR+2)，标注巡航点（红）与失速点（黄）
2. **翼展参数敏感性**：翼展 60%-140% 扫描 → AR/L/D 上升、失速速度不变（S 恒定的工程教学点）
3. **机型对比**：全部机型 AR 与翼载荷双轴柱状图，当前机型高亮，支持缩放
4. **极曲线（Drag Polar）**：CD = CD₀ + CL²/(π·e·AR)，标注巡航点与最佳 L/D 点，含失速后缓降段
5. **飞行包线（Flight Envelope）**：速度-高度可飞区域，失速边界（红）+ 速度限制（黄）+ 升限（绿）围合
6. **爬升性能**：剩余功率法 ROC = (T-D)·V/W，爬升率随高度（0-14000m）变化曲线
7. **雷达对比**：多机型六维雷达图（AR/W-S/L-D/巡航速度/航程/推重比），勾选≤8架对比
   ECharts（echarts.min.js 1MB）本地离线引入，随页面加载。

### 3D 模型联动
- 选有 3D 模型的机型 → 点"🛩 在3D中查看"→ 模型加载到场景
- 改翼展参数 → 模型沿 X 轴（翼展方向）按比例缩放，高度/长度不变
- 通过 CustomEvent 跨闭包通信（engineering.js ↔ index.html）

### 报告导出
- 点"📄 导出报告"→ 新窗口打开自包含 HTML 报告（单机）
- 含：机型信息、输入参数表、计算结果表（含公式列）、Breguet 航程估算 vs 官方偏差
- 含：公式说明与假设条件文档化（ISA/CD₀/e/TSFC/W₁/CLmax）
- 含：数据来源标注（可追溯）
- 底部"打印 / 另存为 PDF"按钮（调用 window.print()，浏览器原生打印对话框）

### 多机型对比报告
- 在"雷达对比"标签中勾选机型（≤8架）
- 点"📊 对比报告"→ 新窗口打开多机型对比报告
- 含：机型一览表、15 项性能参数对比表、关键指标最优值表（L/D/W-S/T-W/起飞距离/航程）
- 含：公式说明、数据来源汇总，可打印为 PDF
